# 安心查（防詐 App 網頁原型）

「安心查」是依據 `GPT專案交接prompt.md` 建立的第一階段網頁原型。使用者可以貼上可疑文字、網址、上傳對話截圖，或匯入 LINE 對話 `.txt`，在瀏覽器本機取得風險提醒、可疑原因與建議行動。

## 本機啟動

需求：Node.js 20.19+ 或 22.12+、npm。

```powershell
npm install
npm run dev
```

終端機會顯示本機網址，通常是 `http://localhost:5173/`。

使用者自願回報、管理後台與核准後資料庫更新的架構及啟用步驟，請見 [docs/REPORTING_BACKEND.md](docs/REPORTING_BACKEND.md)。後台建置後位於 `/admin.html`。

## 驗證

```powershell
npm test
npm run build
npm run preview
```

## 更新政府資料庫

以下指令會下載三份採政府資料開放授權條款第 1 版的資料集，正規化、去重後輸出至 `public/data/threat-intelligence.json`：

```powershell
npm run data:update
```

掃描時只會讀取網站隨附的本機資料庫，不會把使用者輸入傳給政府或第三方網站。

更新完成後可驗證資料筆數、來源、排序、重複值與欄位格式：

```powershell
npm run data:verify
```

`.github/workflows/update-threat-db.yml` 會在推送程式碼時部署 GitHub Pages，並於每天台灣時間 11:20 自動執行資料更新、驗證、測試、建置與重新部署；只有資料內容真的改變時才會建立提交。

## 目前範圍

- 文字與網址規則掃描
- 通用社交工程行為組合判斷（轉移平台、索取資料、持續追催、誘餌活動）
- PNG、JPG、WebP 多張截圖 OCR（一次最多 10 張、每張 20 MB、每批 80 MB；先在本機統一重新編碼，再依選取順序逐張處理，單張中斷時最多自動重試一次）
- 截圖 QR Code 本機解碼；只抽取字串並比對，不會自動開啟或跟隨網址
- 瀏覽器內多語語意 AI，可辨識未命中固定關鍵字的近似詐騙手法
- 搜尋由三份政府開放資料合併的本機涉詐網域資料庫
- 比對去識別化社群詐騙案例話術（不保存發文者姓名、頭像或原始截圖）
- LINE `.txt` 匯入（上限 1 MB，最多分析前 12,000 字）
- 四態結果：高度風險、可疑、未發現已知特徵、無法充分判斷
- 結果頁列出本次實際比對的政府資料集、版次、筆數、命中狀態與判斷限制
- OCR 失敗、可信度不足或截圖資訊不完整時輸出「無法充分判斷」，不以風險分數假裝已充分解析
- 建議行動與 165 快速撥號
- 本機處理，不上傳、不儲存輸入內容
- 官方與可信第三方查證入口（只提供外部連結，不自動傳送輸入內容）
- 響應式、鍵盤操作與降低動態效果支援

## 語意模型與隱私

語意 AI 使用 `Xenova/paraphrase-multilingual-MiniLM-L12-v2` 的 q8 ONNX 版本。首次開啟時會從 Hugging Face 下載約 150 MB 的模型與分詞檔，之後由瀏覽器快取。待檢查訊息不會送給 Hugging Face 或專案伺服器；模型無法載入時，網址資料庫、規則引擎與社群案例比對仍會照常運作。

為提升手機穩定性，若規則、網址或案例庫已找到足夠風險證據，本次檢查會略過大型語意模型；只有證據不足時才延遲載入模型。

語意相似度只作風險提示，不作為認定任何個人或組織涉詐的依據。目前規則與模型皆供產品原型驗證，不應作為正式安全保證。

介面中的分數是「已蒐集到的風險證據分數」，不是詐騙機率。政府資料庫未命中，只代表在該版次及 OCR 可辨識內容中沒有找到相同網域，不能解讀為安全。
