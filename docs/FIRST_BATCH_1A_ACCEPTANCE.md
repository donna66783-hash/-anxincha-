## 正規化與誤報冒煙矩陣

| 情況 | 預期與結果 |
| --- | --- |
| 大小寫、結尾句點、`www.` | 正規化後精確命中；保留原始輸入 |
| 子網域對母網域歷史紀錄 | 命中並標示 `parent-domain` |
| 全形句點 | 轉換為 ASCII 點後比對 |
| 國際化網域／Punycode | 使用 URL 標準轉為 Punycode 後比對 |
| `forms.gle`、`bit.ly`、`t.co`、Facebook、Instagram 根網域 | 不因頁面或子網域紀錄把整個平台判成詐騙 |
| `github.io` 等共用代管 | 只允許完整租戶主機名稱命中，不向上擴大 |

涉詐字串只存在測試記憶體與本地快照，不產生可點擊連結、不開啟、不發出請求。

## 多圖行為

- 最多 10 張，選圖後先顯示縮圖與順序按鈕，再由使用者開始辨識。
- 預設每張獨立分析；整批只取最高優先狀態，不相加不相關圖片的弱訊號。
- 勾選同一段對話後，才比對相鄰 OCR 行的前後重疊並跨圖分析。
- 每張顯示圖片編號、縮圖、OCR 品質、狀態、證據分數、命中項目與本機 OCR 文字。
- 一張失敗仍保留其他成功圖片；排序為 `HIGH_RISK > SUSPICIOUS > INSUFFICIENT_EVIDENCE > NO_KNOWN_SIGNALS`。
