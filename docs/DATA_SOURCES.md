# 防詐資料源與查證平台盤點

更新日期：2026-11-11

## 使用分級

- **外部查證入口**：網站存在且功能已核對，可在產品內提供連結；不代表可抓取或再利用資料。
- **候選資料源**：有公開清單或案例，但需確認資料格式、更新機制、授權與商業使用條件後才能匯入特徵庫。
- **不直接整合**：涉及個人身分、第三方傳輸或商業授權限制，只提供說明或由使用者自行開啟。

## 目前結論

1. 第一版只提供明確標示的外部連結，不自動把使用者輸入內容傳給第三方。
2. 正式特徵庫優先尋找有機器可讀格式、更新日期、版本與清楚商用授權的資料集。
3. 所有命中結果仍使用「可能／提醒」語氣，並保存來源版本與查詢日期，支援更正與下架。
4. Google Safe Browsing 不符合本專案預設商業化方向；除非取得另行協議，正式版應評估 Web Risk 或其他允許商用的來源。

## 待查證

- 各平台是否提供正式 API、更新頻率、速率限制與資料保留規定。
- 165 下載檔案與刑事局附件是否全部適用政府資料開放授權條款。
- MyGoPen 是否接受商業產品以 API 或批次方式整合。
- 對外連結是否需要定期自動檢查失效與網域異動。
