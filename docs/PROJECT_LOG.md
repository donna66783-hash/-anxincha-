# 專案日誌

## 2026-11-11｜第 1 週

### 已完成

- 讀取第二版交接文件並將第一階段定為網頁原型。
- 確認本機 Node.js 24.14.0、npm/npx 11.9.0、Git 2.56.0 可用。
- 建立 Vite + TypeScript 純前端專案。
- 實作文字、網址與 LINE `.txt` 匯入的規則式風險分析。
- 實作高／中／低風險、可疑原因與建議行動介面。
- 加入基本自動測試、響應式版面與無障礙支援。

### 學到與風險

- 規則式分析適合快速驗證解釋方式，但沒有正式測試集前，不能宣稱準確率。
- 目前可疑網址檢查只看網址字面特徵，尚未查詢註冊資料或正式封鎖清單。
- 外部字型由 Google Fonts 載入；功能不依賴字型，但正式隱私審查時應考慮改為系統字型或自託管。

### 數據

- 自動測試案例：3（假檢警、一般訊息、可疑網址）。
- 誤報率／漏報率：尚未量測；第 4 週前建立基準。

### 補充進度：可信查證來源

- 核對數發部網路詐騙通報查詢網、165 全民防騙網、刑事局境外涉詐帳戶與聯徵中心警示帳戶說明。
- 建立 `DATA_SOURCES.md`，區分外部查證入口、候選資料源與不可直接整合的服務。
- 確認 Google Safe Browsing API 原則上限非商業用途；正式商業版需另評估 Web Risk。
- 前端新增六個可信查證／求助入口，且不會自動傳送使用者輸入內容。

### 補充進度：政府資料庫查詢

- 確認三份可下載且採政府資料開放授權條款第 1 版的資料集：數位產業署停止解析清單、165 遭停止解析涉詐網站、165 假投資（博弈）網站。
- 建立 `npm run data:update` 更新流程，將來源正規化、去重並輸出版本化 JSON。
- 掃描流程改為「政府資料庫精確比對＋話術規則＋網址特徵」三層判斷。
- 結果頁會顯示命中網域、來源資料集、資料日期、資料庫版本與筆數。
- 2026-11-11 實際更新結果：151,533 個原始資料列，去重後 127,687 個網域，JSON 約 5.38 MB。
- 自動測試增至 7 項並全數通過。

### 補充進度：每日自動更新

- 建立 GitHub Actions，每天台灣時間 11:20 下載三份政府開放資料。
- 更新後依序執行資料完整性驗證、7 項應用測試與正式建置。
- 新增最低資料量、來源數量、授權標示、網域格式、排序與重複值防護；來源異常時工作流程會失敗，不會提交損壞資料。
- 更新腳本會比較實際內容；資料未變時保留原版本，不製造每日空提交。
- 工作流程加入 GitHub Pages：程式推送與每日資料更新都會在品質閘門通過後部署公開網站。
