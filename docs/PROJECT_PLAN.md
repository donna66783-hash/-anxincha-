## 產品原則

- 對話、錄音與截圖預設只在裝置本地處理。
- 所有結果使用「提醒／可能」，不宣稱能判定詐騙。
- 先服務高風險族群，採大字、少選項、可解釋的介面。
- 原型期維持零成本；任何付費、對外承諾或方向改變先交由擁有者決定。
