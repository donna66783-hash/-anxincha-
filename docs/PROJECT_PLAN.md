# 防詐 App：12 週執行計畫

更新日期：2026-11-11

## 產品原則

- 對話、錄音與截圖預設只在裝置本地處理。
- 所有結果使用「提醒／可能」，不宣稱能判定詐騙。
- 先服務高風險族群，採大字、少選項、可解釋的介面。
- 原型期維持零成本；任何付費、對外承諾或方向改變先交由擁有者決定。

## 本週（第 1 週）

### 目標

建立可以操作與討論的前端基線，讓後續研究、特徵庫與測試都有明確落點。

### 任務

- [x] 確認本機 Node.js、npm、Git 可用。

- [x] 完成文字／網址／LINE `.txt` 第一版流程。

- [ ] 查證 Android／iOS 平台限制與 Google Play 最新政策。

- [x] 建立三份政府開放資料的每日自動更新與完整性驗證。

## 階段 0 驗收指標

- 測試集至少 300 則，分詐騙類型並保存來源與授權欄位。
- 每次規則或模型變更都輸出誤報率、漏報率與各類型召回率。
- 5–8 位長輩可在無協助下完成「貼上／匯入 → 看懂結果 → 說出下一步」。
- 所有輸入內容在瀏覽器開發者工具中確認沒有網路上傳。
